FAQ sobre el código de referencia Fizz

¿Cómo uso un código de referencia Fizz?

Copia el código, comienza la activación de tu primer plan Fizz y escríbelo en el campo de referencia antes de enviar el pedido.

¿Es este un sitio oficial de Fizz?

No. ProjetFZ es un sitio independiente que comparte un código de referencia Fizz. Las condiciones finales siempre son las que muestra Fizz.

¿La recompensa se aplica en la primera factura?

Fizz indica que la recompensa generalmente se aplica después de que el nuevo miembro haya completado dos meses de servicio elegible, así que no siempre es un descuento inmediato.

¿Puedo agregar un código después de inscribirme?

Fizz indica que el código debe ingresarse durante la activación del primer plan; generalmente no se puede agregar retroactivamente.

¿El código funciona para móvil e Internet?

El programa de referencia Fizz puede aplicar a un primer plan elegible. Verifica siempre las condiciones mostradas por Fizz antes de completar la suscripción.

¿El monto de 25$ está garantizado?

No. El monto puede cambiar sin previo aviso según las condiciones de Fizz. Esta página muestra el valor observado en la última verificación.

¿Por qué el código también está en el enlace?

El enlace agrega el parámetro de referencia para facilitar el recorrido, pero conserva el código copiado por si Fizz te pide pegarlo durante la activación.

ProjetFZ es un sitio independiente. Fizz es una marca de su respectivo propietario.
